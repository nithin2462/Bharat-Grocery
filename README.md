# Bharat Grocery — Starter MVP

## Run it
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or another modern browser.
3. Add items, adjust quantities and unit prices, switch between Household and Shop Owner modes, and print the bill.

## Included in this starter
- Grocery list with editable item names, quantities, units, categories and prices
- kg, g, litre, ml, piece and pack units
- Automatic line totals and grand total
- Household and Shop Owner views
- Common grocery starter list
- Bill preview and browser print
- English, Kannada and Hindi starter interface labels
- Browser local storage persistence on the current device

## Important limitations
This is a runnable front-end prototype, not yet a production cloud app. Data currently stays in the browser on the device where it was entered. Multi-device sync, secure user accounts, cloud database, barcode scanning, GST configuration, supplier management, backups, and a complete 22-language translation pack are not included yet. These need a backend and deployment configuration.
